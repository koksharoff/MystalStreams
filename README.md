# MystalStreams

Плагин для серверов Minecraft на **Paper 1.21**, который позволяет игрокам объявлять о начале своих трансляций на YouTube или Twitch. При запуске стрима всем игрокам на сервере приходит сообщение с кликабельной ссылкой, а сервер выполняет настраиваемые консольные команды.

## Возможности

- Команда `/stream <ссылка>` — объявление о начале стрима с кликабельной кнопкой **[ПЕРЕЙТИ]** в чате
- Команда `/stream off` — завершение стрима
- Проверка ссылок: принимаются только `youtube.com`, `youtu.be` и `twitch.tv`
- Автоматическое завершение стрима при выходе игрока с сервера
- Перезарядка команды (1 час) с правом на её обход
- Настраиваемые сообщения с поддержкой цветовых кодов `&`
- Настраиваемые консольные команды при старте и остановке стрима
- Хранение активных стримов в SQLite (`plugins/MystalStreams/streams.db`)
- Автодополнение `off` по Tab

## Требования

| Компонент | Версия |
|-----------|--------|
| Сервер    | Paper 1.21.x (собирается против `paper-api 1.21.8`) |
| Java      | 21 |

## Установка

1. Скачайте `MystalStreams-1.0.jar` (или соберите плагин сами, см. ниже).
2. Положите JAR в папку `plugins/` сервера.
3. Перезапустите сервер — будет создана папка `plugins/MystalStreams/` с `config.yml`.
4. При необходимости отредактируйте `config.yml` и перезапустите сервер.

> Используйте JAR, собранный через `maven-shade-plugin`: в него встроен драйвер `sqlite-jdbc`.

## Команды

| Команда | Описание |
|---------|----------|
| `/stream <ссылка>` | Начать стрим и оповестить всех игроков. Схему `https://` можно не указывать. |
| `/stream off` | Завершить текущий стрим. |

Примеры:

```
/stream https://www.twitch.tv/username
/stream youtube.com/watch?v=dQw4w9WgXcQ
/stream off
```

Команда доступна только игрокам (не из консоли).

## Права

| Право | Описание | По умолчанию |
|-------|----------|--------------|
| `mystalstreams.use` | Доступ к команде `/stream` | все игроки |
| `mystalstreams.nocooldown` | Обход перезарядки команды | операторы |

## Конфигурация

`plugins/MystalStreams/config.yml`:

```yaml
messages:
  announce: "&eИгрок {player} начал стрим! Нажмите &nздесь&r&e чтобы присоединиться"
  invalid_url: "&cНедопустимая ссылка! Только YouTube/Twitch"
  cooldown: "&cПодождите {time} секунд перед повторным использованием"
  stream_off: "&aСтрим остановлен"
  not_streaming: "&cУ вас нет активного стрима"
  no_permission: "&cНедостаточно прав!"

commands:
  on_start: "say [Стрим] Игрок {player} начал трансляцию!"
  on_stop: "say [Стрим] Игрок {player} завершил трансляцию"
```

**Плейсхолдеры:**

- `{player}` — ник игрока (в `announce`, `on_start`, `on_stop`)
- `{time}` — оставшееся время перезарядки в секундах (в `cooldown`)

К сообщению `announce` автоматически добавляется кнопка **[ПЕРЕЙТИ]**, открывающая ссылку на стрим.

Команды из раздела `commands` выполняются от имени консоли, поэтому туда можно подставить любые команды сервера или других плагинов (например, выдачу префикса стримера через LuckPerms).

## Сборка из исходников

Нужны JDK 21 и Maven:

```bash
git clone https://github.com/koksharoff/MystalStreams.git
cd MystalStreams
mvn clean package
```

Готовый плагин появится в `target/MystalStreams-1.0.jar`.


## Известные ограничения

- Длительность перезарядки (1 час) задана в коде и не настраивается через конфиг.
- Перезарядка хранится в памяти и сбрасывается при перезапуске сервера.
- Перезарядка начинается до проверки ссылки, поэтому ввод неверной ссылки тоже её запускает.
- Ссылки вида `m.youtube.com` и `m.twitch.tv` не проходят проверку.
- Активные стримы в базе не очищаются при перезапуске сервера.
